# CVision Frontend

## Setup Project

1. **Clone repository**
   ```bash
   git clone <repository-url>
   cd frontend
   ```

2. **Install dependensi**
   ```bash
   npm install
   ```

3. **Konfigurasi Backend**
   Pastikan backend berjalan di `http://localhost:3000` (atau sesuaikan `BASE_URL` di `src/services/api.ts`).

4. **Menjalankan aplikasi (Development)**
   ```bash
   npm run dev
   ```

5. **Build untuk Produksi**
   ```bash
   npm run build
   ```

## Teknologi Utama
- **Framework:** React 19
- **Build Tool:** Vite
- **Styling:** Tailwind CSS 4 & DaisyUI
- **Icons:** Lucide React
- **Router:** React Router Dom
